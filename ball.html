Project Description

This 2D Breakout game is a sample from CIS166AA, a course I taught as residential faculty in the Web Design program at Mesa Community College during the 2022–2023 and 2023–2024 school years.

The project demonstrates JavaScript concepts through an interactive game, adapted from the MDN 2D Breakout tutorial.

Try the game

Select “Start the game!” to begin. Move the paddle with the left and right arrow keys or your mouse to keep the ball in play and break the bricks. The start button disappears when the game begins.

This game requires a browser that supports HTML canvas.
